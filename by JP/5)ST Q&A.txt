	🔹 Core Manual Testing

1. Can you explain the difference between Smoke testing and Sanity testing? When would you use each?
   Answer: 
	→ Smoke Testing is done after getting a new build "to check if the main and basic features "of the application are working fine.It helps to make sure the build is stable for further testing.

	→ Sanity Testing is done during the release phase to check the main functionalities of the application without going deeper.

*************
2. Walk me through the Software Testing Life Cycle (STLC) you followed in your project.
   Answer: 

→ Requirement Analysis 
	* In this phase, we study the requirements (like SRS or BRD) to understand what needs to be tested.
	* We identify testable requirements and clarify any doubts with the Business Analyst or Developer.

→ Test Planning
	* Here, the Test Lead prepares the Test Plan which defines the scope, objectives, resources, tools, schedule, and risk management.
	* It also defines entry and exit criteria for testing.

→ Test Case Design 
	* In this phase, we prepare test cases, test data, and test scripts based on the requirements.
	* We cover both positive and negative test scenarios to ensure full coverage.

→ Test Execution 
	* We execute the prepared test cases in the test environment and record the results as Pass or Fail.
	* If any test fails, we log the defect in a defect tracking tool like Jira.

→ Defect Reporting 
	* When a defect is found, we report it to the developer with proper details — steps to reproduce, severity, screenshots, etc.
	* We then retest once the issue is fixed and close it after verification.

→ Test Closure.
	* After all testing activities are done, we prepare a Test Summary Report and conduct a closure meeting.
	* We discuss what went well, what needs improvement, and lessons learned for future projects.

2. When do you use XPath over CSS locators?
   Answer:
	→ Use XPath when you need to navigate through complex hierarchies or handle dynamic elements.
	→ XPath supports both forward and backward traversal, while CSS does not.
	→ CSS is faster and preferred for simple attributes, but XPath is more powerful for conditions and parent-child relations.

************
3. How to get a specific value from a dropdown and reuse it in verifications?
  Answer:
	Use the Select class in Selenium

************
4. When do we use JavaScript Executors?
   Answer:
	We use JavaScriptExecutor when Selenium methods fail to interact with certain elements like hidden fields, dynamic elements, or for scrolling actions.
Common uses:
	→ Click hidden elements
	→ Scroll the page
	→ Fetch browser details
	→ Highlight elements

************
5. Is it possible to validate CAPTCHA using Selenium? If yes, how?
   Answer: 
	Selenium alone cannot automate CAPTCHA since it’s meant to prevent automation.
Workarounds:
	→ Bypass CAPTCHA in the test environment.
	→ Use mock data or disable CAPTCHA for automation users.
	→ Use third-party APIs (like 2Captcha or OCR tools) — but this is not recommended for real testing due to security and ethics.

************
6. What should be the ideal way to store data using Selenium WebDriver only?
   Answer:
	Selenium WebDriver alone does not store data, but for temporary storage:
		→ Use variables or HashMap in code for runtime data.
		→ For larger data, integrate with Excel, CSV, or Database using libraries like Apache POI or JDBC.
		→ Use Property files for configuration data.

************
7. Is it possible to use XPath like parent/child/node? If yes, provide an example.
   Answer:
	Yes. XPath supports navigation through parent/child/sibling relationships.
Example:
	→ // Child node
//div[@class='container']/child::input[1]

	→ // Parent node
//input[@id='email']/parent::div

	→ // Following sibling
//label[text()='Username']/following-sibling::input

************
8. What happens if you receive browser notifications during test automation execution?
  Answer:
	→ Browser notifications can interrupt automation.
Solutions:
	ChromeOptions or FirefoxProfile can disable notifications.

Example:
	ChromeOptions options = new ChromeOptions();
	options.addArguments("--disable-notifications");
	WebDriver driver = new ChromeDriver(options);

************
9. Why does Stale Element Exception occur, and how to handle it?
 Answer:
	Reason: The element was found earlier but the page was refreshed or DOM changed before interaction.

Solution:
	→ Re-locate the element before performing the action.
	→ Use WebDriverWait to wait until the element is stable.

************
10. What is Invalid Certificate Exception?
   Answer:
	Occurs when the website has an SSL certificate issue and the browser blocks access.
Solution:
	→ Use DesiredCapabilities or Options to accept insecure certificates.

Example:
	ChromeOptions options = new ChromeOptions();
	options.setAcceptInsecureCerts(true);
	WebDriver driver = new ChromeDriver(options);

   Answer:

************
3. Difference between INNER JOIN and LEFT JOIN.
   Answer: 
	→ INNER JOIN returns matching rows; 
	→ LEFT JOIN returns all left table rows with matched right rows or NULL.

************
4. If duplicate records exist, how do you fetch only unique values?
   Answer: 
	Use SELECT DISTINCT column_name FROM table;

************
5. How do you check if a column has NULL values?
   Answer:
	SELECT * FROM table WHERE column_name IS NULL;

----
Q1. Query to find duplicate records in a table?
    Answer: 
	SELECT column_name, COUNT(*) FROM table GROUP BY column_name HAVING COUNT(*) > 1;

************
Q2. Query to get orders placed in the last 7 days?
    Answer: 
	SELECT * FROM Orders WHERE OrderDate >= NOW() - INTERVAL 7 DAY;

-----
Q1. How to find the 3rd highest salary in a table?
    Answer:
	 SELECT DISTINCT Salary FROM Employees ORDER BY Salary DESC LIMIT 1 OFFSET 2;

************
Q2. How do you join three tables?
    Answer: 
	SELECT * FROM A INNER JOIN B ON A.id = B.id INNER JOIN C ON B.id = C.id;

************
Q3. What is the difference between WHERE and HAVING?
    Answer:
